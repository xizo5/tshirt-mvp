使用说明
1. 选择「文字」直接输入内容，或切到「图片」上传透明底 PNG。
2. 拖动大小 / 位置 / 旋转，把印花放到胸前合适区域。
3. 「褶皱跟随强度」拉高，图案会随底图布料褶皱弯曲，更像真实印刷。
4. 点「下载预览图」保存成品，发给客户确认。
生产端说明（PSD / 印刷件）
本页 = 照片底图 + 褶皱位移 + 印染叠加的浏览器实时合成。正式生产时：后端用同一套坐标生成 300dpi 1:1 印刷文件（Sharp / Pillow），预览与印刷同源，所见即所得。
若走 Photoshop：基于 assets/tshirt_base.jpg 建样机 —— 置入底图 → 胸前区域新建智能对象图层 → 双击放入用户 Logo，褶皱会随照片自动变形，导出即可作为确认图。

下单生产（MVP 演示）

正式流程为：

  1. 客户确认当前预览效果
  2. 后端用同一套印花坐标生成 300dpi 1:1 印刷文件
  3. 客服复核预览图与印刷文件一致
  4. 安排工厂生产并发货

当前为演示版本，「下单」不会真实提交订单。
